# Дизайн-система личного сайта

Этот файл — единый источник визуальных решений проекта. Базовая тема сайта светлая, с холодной нейтрально-синей палитрой.

## Типографика

Основной и единственный шрифт интерфейса — JetBrains Mono. Он подключается локально через `@fontsource-variable/jetbrains-mono`.

- Display: weight 700, line-height 0.96, отрицательный tracking только для крупного hero.
- Body: weight 400–500, line-height 1.55.
- Navigation and controls: weight 600–700.
- Utility labels: weight 600–700 с умеренным tracking.
- Fallback: `ui-monospace, SFMono-Regular, Consolas, monospace`.

Не подключай JetBrains Mono через CDN или Google Fonts.

## Принципы использования цвета

- `--blue-1`–`--blue-3`: фон страницы, секций и спокойных поверхностей.
- `--blue-4`–`--blue-6`: границы, разделители и состояния `hover` у светлых элементов.
- `--blue-7`–`--blue-8`: второстепенные акценты и активные границы.
- `--blue-9`: основной акцент, кнопки и ключевые интерактивные элементы.
- `--blue-10`: `hover` основного акцента.
- `--blue-11`: ссылки, второстепенный акцент и текст на светлых поверхностях — только после проверки контраста.
- `--blue-12`: основной насыщенный текст и самые тёмные элементы.
- `--blue-contrast`: текст и иконки поверх основного акцента.
- `--blue-surface`: полупрозрачные акцентные поверхности.
- `--blue-indicator` и `--blue-track`: индикаторы, переключатели и прогресс.
- Альфа-токены `--blue-a1`–`--blue-a12` используй для наложений, подсветки и интерактивных состояний, когда фон должен просвечивать.
- Не вставляй значения цветов напрямую в компоненты. Используй CSS-переменные.
- Перед выпуском проверяй контраст текста и интерактивных состояний по WCAG 2.2 AA.

## Семантические роли

При реализации интерфейса поверх базовой шкалы создай семантический слой. Начальная рекомендуемая привязка:

```css
:root {
  --color-canvas: var(--blue-1);
  --color-surface: var(--blue-2);
  --color-surface-raised: var(--blue-contrast);
  --color-border: var(--blue-4);
  --color-border-strong: var(--blue-7);
  --color-text: var(--blue-12);
  --color-text-muted: var(--blue-11);
  --color-accent: var(--blue-9);
  --color-accent-hover: var(--blue-10);
  --color-on-accent: var(--blue-contrast);
  --color-focus: var(--blue-8);
}
```

Семантические токены можно уточнять по мере развития сайта, сохраняя базовую палитру неизменной.

## Сетка и движение

- Максимальная ширина общего контейнера — `1280px` (`--layout-max`).
- Горизонтальный gutter задаётся токеном `--layout-gutter`: `16px` по умолчанию, `24px` от `430px`, `32px` от `768px`, `40px` от `1024px`.
- Контролы, обычные поверхности и крупные смысловые блоки используют единую шкалу радиусов: `12px` (`--radius-control`), `18px` (`--radius-surface`) и `24px` (`--radius-feature`). Круглые маркеры и pill-элементы остаются исключением.
- Быстрый отклик — `160ms` (`--motion-fast`), смена состояния — `280ms` (`--motion-state`), смысловое появление — `500ms` (`--motion-reveal`).
- Общее easing движения — `cubic-bezier(0.22, 1, 0.36, 1)` (`--motion-ease`).
- Последовательность hero появляется один раз по порядку «Проблема → Решение → Экономика → Разработка → Запуск → Аналитика». Нормализованный SVG-сигнал проходит путь за `500ms`, затем шесть узлов проявляются с шагом `70ms`. Наблюдатель отключается после первого запуска; повторов и фоновых циклов нет.
- Интерактивный наклон ProfileCard ограничен `1.5deg`; на touch-устройствах и при `prefers-reduced-motion` он отключён.

## Evidence-first Ice

- Характер интерфейса создаёт холодная цифровая среда: спокойные синие поверхности, тонкие границы, прозрачные ледяные слои и один управляемый световой сигнал. Декор не конкурирует с текстом и доказательствами выполненной работы.
- В проектной карточке сгенерированный фон отвечает только за атмосферу. Поверх него всегда остаются отдельными слоями точный логотип продукта и реальный интерфейс; Imagen не генерирует логотипы, текст или псевдоинтерфейсы.
- Обе основные карточки проектов используют медиа `3:2`, равные колонки от `768px` и одинаковую верхнюю линию. На mobile карточка полностью работает без hover.
- Реактивная глубина включается только при `(hover: hover) and (pointer: fine)`: задний слой следует за указателем с небольшим смещением, карточка поднимается не более чем на `2px`, а доказательный скриншот не масштабируется агрессивно. Декоративные копии не получают pointer-listeners.
- Для каждой бизнес-задачи сначала читаются четыре действия, затем с шагом `45ms` проявляются ровно четыре компактных результата. Live-region сообщает только название выбранной задачи.
- При `prefers-reduced-motion` SVG-путь, узлы, действия, результаты и проектные слои сразу показаны в конечном статичном состоянии.

## Иерархия поверхностей

- Основную глубину создают фон секции, граница и размер блока. Тень не является обязательной для каждой карточки.
- Самая заметная тень остаётся у ProfileCard как у главного персонального объекта hero. Навигация использует более спокойную тень, а финальный CTA отделяется от фона границей без дополнительной тени.
- Вторичный текст использует `--color-text-muted`, привязанный к контрастному `--blue-11`; для длинного основного текста предпочтителен `--color-text`.
