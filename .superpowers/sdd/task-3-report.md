- Сохранён H2 «От бизнес-проблемы до измеримого результата», а результаты четырёх задач заменены на согласованные проверяемые операционные эффекты без новых чисел и без повтора действий. No-JS версия автоматически получает тот же текст из `siteContent`.

- Результаты задачи начинают появляться после полного `280ms` раскрытия действий и затем идут с шагом `45ms`.
- ProjectVisual подписывает pointer-listeners только при fine-hover и выключенном reduced motion, реагирует на изменение media query и сбрасывает CSS-переменные при отключении и cleanup.
