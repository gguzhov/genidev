# Design

## Visual world

Evidence-first Ice — холодная цифровая среда, в которой спокойные синие поверхности, тонкие границы и направленный свет помогают читать доказательства работы. Общий фон — один медленный полноэкранный iridescence WebGL-поток в светлой ледяной палитре; он деликатно реагирует на точный указатель и останавливается при скрытой вкладке или reduced motion, поэтому интерфейс остаётся собранным, а не «нейросетевым».

## Composition

- Общий контейнер и gutters определены в `docs/design-system.md`.
- Hero строится вокруг полноширинного позиционирования, короткого обещания, одного CTA и портрета.
- Бизнес-задачи сгруппированы по шести направлениям: маркетинг, продажи, управление, операционные процессы, AI-инфраструктура, технический консалтинг и обучение. Внутри — три конкретных продукта, где пример цифрового решения связан с наблюдаемым изменением в работе; открытая строка «И другое цифровое решение» вынесена из карточек.
- Витрина проектов использует светлые абстрактные ледяные обложки `3:2`: один тематический мотив по краям, чистый центр и точный логотип на центральной стеклянной пластине. Реальные интерфейсы и фотографии остаются доказательствами внутри полного кейса.
- Кейсы — не техническая документация: проблема, решение, польза для бизнеса, четыре результата, галерея/видео и материалы проекта.

## Motion

- Главный authored moment — самолёт, контрольные точки и заполнение одной SVG-дороги в карьерном пути; все три слоя используют одну геометрию и один нормализованный прогресс.
- Iridescence-шейдер движется с низкой скоростью, при скрытой вкладке ставится на паузу и имеет статичный CSS fallback; дополнительные сетевые и орбитальные слои не используются.
- Орбита CTA выполняет один ограниченный проход при появлении и коротко реагирует на hover/focus.
- Все движения имеют статичное финальное состояние при `prefers-reduced-motion`.

## Project card system

- Категории отражают область и тип решения: `Medtech / Web / AI`, `Сеть / Web / Автоматизация`, `Телеком / Дата-центр`.
- Медиа 3:2, одинаковая высота в строке, логотип выровнен по центру.
- Под медиа: метки, название, короткое человеческое описание и кнопка «Подробнее». Четыре подтверждённых результата раскрываются внутри кейса.
- Весь объект открывается мышью, касанием и клавиатурой; hover только усиливает глубину.

## Copy

- Заголовки отвечают на вопрос посетителя, без eyebrow и нумерации секций.
- Используются конкретные глаголы: «разработать», «связать», «запустить», «измерить».
- Не используются: «комплексный подход», «под ключ», «эффективные решения», «цифровая трансформация», «внедряю инновации».
